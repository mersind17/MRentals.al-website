# mrentals.al

Faqja e MRentals (makina me qera në Elbasan dhe Aeroportin e Rinasit) — Astro 7, static, e ndërtuar nga dizajni në Figma.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # dist/
```

- Tekstet shqip/anglisht: `src/i18n.ts`
- Makinat dhe çmimet: `src/data/cars.ts`
- Kontakti, vlerësimet: `src/data/site.ts`
- Faqja e Elbasanit: `src/data/locations.ts`
- Ridrejtimet (URL-të e vjetra) dhe cache: `vercel.json`
